# 🏦 Python Bank Account System

A beginner-friendly **Python OOP project** that simulates a simple bank account.

This project was created while learning the fundamentals of **Object-Oriented Programming (OOP)** in Python.

## 📌 Features

* Create a bank account with an owner and balance
* Deposit money
* Withdraw money
* Check whether sufficient balance is available
* Interactive user menu
* Uses a Python class and object

## 🧠 Concepts Used

* Classes
* Objects / Instances
* `__init__`
* `self`
* Instance attributes
* Methods
* Conditional statements
* User input
* Basic arithmetic
* Encapsulation fundamentals

## ⚙️ How It Works

The `Bank` class stores:

* **Owner** — Account holder's name
* **Balance** — Current account balance

The program allows the user to choose between depositing and withdrawing money.

Before a withdrawal is completed, the program checks whether the account has enough balance.

## 💻 Example

```text
What would you like to do?
1. Deposit
2. Withdraw

Enter your choice: 2
Enter the amount you want to withdraw: 1500

3500 is the updated balance
```

If the withdrawal amount is greater than the available balance:

```text
INSUFFICIENT BALANCE
```

## 🚀 How to Run

Make sure Python is installed on your computer.

Then run:

```bash
python bank.py
```
